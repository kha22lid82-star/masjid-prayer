📁 الملفات في هذا المجلد:
  index.html    ← التطبيق الرئيسي
  manifest.json ← إعدادات PWA
  sw.js         ← Service Worker للعمل offline
  icon-192.png  ← أيقونة التطبيق
  icon-512.png  ← أيقونة التطبيق (كبيرة)

════════════════════════════════════════════
المرحلة الأولى — رفع الملفات على GitHub Pages
════════════════════════════════════════════

١. افتح github.com وسجّل دخول (أو أنشئ حساباً مجاناً)

٢. اضغط "New Repository" واختر:
   - اسم: masjid-prayer (أو أي اسم)
   - Public ✅
   - اضغط "Create repository"

٣. اضغط "uploading an existing file"

٤. ارفع جميع الملفات الخمسة دفعة واحدة:
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png

٥. اضغط "Commit changes"

٦. اذهب لـ Settings ← Pages ← Source: main ← Save

٧. انتظر دقيقة ثم ستجد الرابط:
   https://username.github.io/masjid-prayer

اختبر الرابط في المتصفح — يجب أن يفتح التطبيق ✅

════════════════════════════════════════════
المرحلة الثانية — تحويل لـ APK
════════════════════════════════════════════

الطريقة أ — WebIntoApp.com (مجاني):
  ١. افتح webintoapp.com
  ٢. الصق الرابط: https://username.github.io/masjid-prayer
  ٣. اسم التطبيق: مواقيت الصلاة
  ٤. Package name: com.masjid.prayer
  ٥. ✅ Fullscreen    ✅ Portrait    ✅ Keep Screen On
  ٦. اضغط "Create App" ← حمّل APK

الطريقة ب — WebViewGold (مدفوع - 19$):
  أفضل جودة وخيارات أكثر
  webviewgold.com

════════════════════════════════════════════
المرحلة الثالثة — تثبيت APK على MI Box
════════════════════════════════════════════

١. انقل ملف .apk إلى فلاشة USB

٢. في MI Box:
   Settings ← More Settings ← Security
   ← Unknown Sources ← ON ✅

٣. افتح مدير الملفات (X-plore)
   ← اختر الفلاشة ← اضغط على .apk
   ← Install ← Open

٤. للتشغيل التلقائي:
   ثبّت تطبيق "Autostart" من Play Store
   واختر تطبيق مواقيت الصلاة
